# Sales & Customer Analytics Dashboard

## 📌 Project Overview

This project analyzes sales and customer transaction data to identify
important business trends and provide data-driven insights.

The project covers the complete data analytics workflow, starting from
raw data cleaning and exploratory analysis to SQL analysis, Excel
reporting, and an interactive Power BI dashboard.

---

## 🎯 Business Objective

The main objective of this project is to understand:

- Overall sales and profit performance
- Sales trends over time
- Product and category performance
- Regional performance
- Customer purchasing behavior
- Profitability and discount patterns
- Areas where the business can improve
